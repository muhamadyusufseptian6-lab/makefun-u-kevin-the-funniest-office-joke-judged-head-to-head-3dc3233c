One single-line joke about office life — the whole entry. The office printer
has never once been late to a deadline. It just makes sure you aren't either.

## The joke

> The office printer has never once been late to a deadline — it just makes sure I am.

## How it works

`main.ts` (Node 22+, stdlib only, deterministic) writes that one line to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. Nothing else is written, no network, no
secrets, no input read.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
